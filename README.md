# 🌀 MazeRunner Project Overview

**MazeRunner** is a blockchain-powered 2D maze game built on the **Linera Blockchain**. Players navigate mazes to earn token rewards, gain XP, and unlock NFT passkeys as they advance through levels.

---

## 🎯 Project Overview
MazeRunner integrates gameplay with on-chain mechanics. Players earn rewards and interact with smart contracts.

### Core Features
- 🧩 **Maze Challenges:** Players navigate 10 progressive maze levels (25×25 to 35×35 cells).
- 💰 **Token Rewards:** Players earn Linera tokens (5 points for main token, 2 points for mini tokens).
- ⏱️ **Time-Based Gameplay:** Complete mazes within dynamic time limits (30-48 seconds).
- 📱 **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- 🔒 **On-Chain Fairness:** Game logic and rewards handled transparently via smart contracts.
- 🎯 **Leaderboard:** Top 5 winners per game tracked on blockchain.

---

## 🧑‍💻 Use Cases
- **Play-to-Earn Gaming:** Players earn real blockchain tokens and NFTs by completing mazes and achieving high scores.
- **Skill-Based Competitions:** Compete on a global leaderboard for rewards, fostering a competitive gaming community.
- **On-Chain Achievements:** Unlock NFT passkeys and badges for milestones, provable on the Linera blockchain.
- **Educational Demos:** Demonstrates blockchain gaming, wallet integration, and microchain scalability for developers and students.
- **Tokenized Tournaments:** Host special events or tournaments with on-chain prize pools and verifiable results.
- **Web3 Onboarding:** Provides a fun, low-barrier way for new users to experience wallets, tokens, and NFTs.

---

## 🚀 Vision
MazeRunner aims to be a flagship example of scalable, fair, and rewarding blockchain gaming. By leveraging Linera's microchains, the game aspires to:
- Enable massive, parallel player participation without bottlenecks.
- Offer transparent, tamper-proof rewards and leaderboards.
- Serve as a template for future Web3 games and educational projects.
- Foster a vibrant community of players, developers, and creators.
